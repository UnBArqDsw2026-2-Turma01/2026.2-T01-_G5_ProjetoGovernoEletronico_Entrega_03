# 3.3. Iniciativas Extras (Padrões de Projeto)

Esta página documenta as **Iniciativas Extras** desenvolvidas pelos membros da subequipe no escopo da Entrega 3, visando elevar a qualidade técnica, a governança de código e a padronização do desenvolvimento dos Padrões de Projeto.

## Tabela de Iniciativas Extras

| Item | Iniciativa Extra | Descrição | Autor(es) |
| :--: | :--- | :--- | :--- |
| **01** | [Padrão de Testes (SubEquipe 1)](../Projeto/ExtrasEntrega3/PadraoDeTestes.md) | Guia e especificação de padronização para elaboração de testes unitários e de integração (AAA, FIRST, Vitest e React Testing Library) para os padrões GoF Criacionais. | [Giovani Coelho](https://github.com/Gotc2607) |
| **02** | [Guia de GoF Comportamental](../Projeto/ExtrasEntrega3/GuiaGoFComportamental.md) | Referência teórica sobre os padrões GoF Comportamentais, com foco em Strategy e Template Method: intenção, participantes, diagramas genéricos e comparação entre os dois padrões. | [Davi Ursulino de Oliveira](https://github.com/DaviUrsulino) |
| **03** | [Guia de Padrões de Projeto em JavaScript e TypeScript](../Projeto/ExtrasEntrega3/PadroesEmergentes_JS-TS.md) | Referência teórica sobre os padrões de projeto em JavaScript e TypeScript | [Gabriel Mota](https://github.com/Gabro-MO) |
| **04** | [Padrão de Pull Requests](../Projeto/ExtrasEntrega3/PadraoPullRequests.md) | Guia de diretrizes e template padronizado para abertura, revisão e integração de Pull Requests (PRs) no repositório do projeto. | [Nicole Jovita](https://github.com/nicolejovita) |
